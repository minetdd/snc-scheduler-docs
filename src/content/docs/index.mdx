## What is SNC Scheduler?

SNC Scheduler is a self-hosted appointment booking app. Set your weekly availability, define your services, and share a booking link — clients pick a time, you get a confirmation email and a calendar event.

<CardGrid stagger>
  <Card title="Quick setup" icon="rocket">
    Run `npm run setup` and you're up in minutes — no manual config files.
  </Card>
  <Card title="Embeddable" icon="puzzle">
    Drop a single `<iframe>` onto any website to embed the booking form.
  </Card>
  <Card title="Calendar sync" icon="calendar">
    Confirmed bookings appear in Google Calendar automatically.
  </Card>
  <Card title="Self-hosted" icon="laptop">
    Deploy on Render, Vercel, or anywhere Node.js runs. You own the data.
  </Card>
