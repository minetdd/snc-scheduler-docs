---
title: Services
description: Define the types of sessions clients can book.
---

Services (called *service types*) define what clients can book — the name, duration, buffer time, and optional price.

## Creating a service

1. Go to **Admin → Services**
2. Click **Add Service**
3. Fill in the fields and save

## Fields

| Field | Description |
|---|---|
| **Name** | Shown to clients on the booking page (e.g. "Standard Session") |
| **Description** | Optional — shown below the name on the booking page |
| **Duration** | How long the session lasts in minutes |
| **Buffer time** | Gap added after each booking before the next slot opens |
| **Price** | Optional — shown as a badge on the booking page |
| **Colour** | Used to identify the service on the admin calendar |

## Deactivating a service

Toggle a service inactive to hide it from the public booking page without deleting it. Existing bookings for that service are not affected.
